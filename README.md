# Shivay Traders Website — Premium V2

## Major changes
- Removed the old “Collection” navigation and homepage section.
- Added a dedicated `products.html` page.
- Added category filters: All, Bangles, Rings, Bracelets, Mala, Rudraksha, Kada, Dhaga and Sindoor.
- Added product search by product name or code.
- Added 24 temporary product cards so the page structure is fully visible.
- Category cards on the home page now open the products page with that category already selected.
- Upgraded the entire design to a more premium editorial white, champagne-gold and black style.
- Kept direct WhatsApp enquiry and no online checkout.

## Preview
1. Extract the ZIP.
2. Open the folder.
3. Double-click `index.html`.
4. Click “Products” in the header to open the dedicated filtered catalogue.

## Product management later
Temporary products are stored in `js/products.js`.
When real products are ready, replace each item’s name, code, category and symbol, and add product image support.

## Mobile spacing fix
The products page has been updated so the category filter sits directly below the Product Catalogue banner on mobile. The stylesheet URL also includes a cache-busting version so the latest CSS loads after refresh.
